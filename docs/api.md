# IoT REST API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` | 登录 |
| GET | `/api/admin/dashboard` | 设备运营态势 |
| GET | `/api/admin/work-orders` | 设备任务 |
| GET | `/api/shopfloor/dashboard` | 现场运维工作台 |
| POST | `/api/shopfloor/work-orders/{id}/reports` | 提交巡检数据 |
